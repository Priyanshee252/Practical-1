# My Webpage Project

## What is this project about?
This is a simple webpage project made by me as a first-year student to
practice and learn the basics of web development. The goal of this project
is to create a basic webpage using HTML, CSS, and JavaScript, and to
understand how these three work together to build a website.

## Folder Structure
```
project-name/
│
├── index.html      -> the main webpage file
├── style.css        -> file for design and colors
├── script.js         -> file for adding interactivity
├── images/            -> folder to store images used in the page
└── README.md        -> this file (project info)
```

## Technologies Used
- **HTML** – used to create the structure of the webpage
- **CSS** – used to style the webpage (colors, fonts, layout)
- **JavaScript** – used to make the webpage interactive

## How to Run this Project on Your Computer

1. Download or clone this project folder to your computer.
   ```
   git clone https://github.com/your-username/project-name.git
   ```

2. Open the project folder.

3. Double-click on the `index.html` file.
   - It will open automatically in your default web browser.
   - That's it! You can now see the webpage running.

   (Optional) If you want to use a live preview while editing:
   - Open the folder in VS Code
   - Install the "Live Server" extension
   - Right-click on `index.html` and select "Open with Live Server"
